## About this repo

This repo hosts the source code for [fandipres.my.id](https://fandipres.my.id), my personal academic portfolio site. It showcases education and work experience, academic publications, research, teaching, community service, intellectual property records, and a list of personal projects, available in both Indonesian and English. Built with plain HTML, JavaScript, and Tailwind CSS with no framework, then auto-prerendered via GitHub Actions to stay search-engine friendly.
